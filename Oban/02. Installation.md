# Oban : Installation

https://hexdocs.pm/oban/Oban.html

# 1. Ajouter Oban dans les dépendances

Dans le fichier `mix.exs` :

```elixir
defp deps do
  [
    {:oban, "~> 2.19"}
  ]
end
```

`mix deps.get`

# 2. Créer la migration pour les jobs

`mix ecto.gen.migration add_oban_jobs_table`

```elixir
defmodule MyApp.Repo.Migrations.AddObanJobsTable do
  use Ecto.Migration

  def up do
    Oban.Migration.up(version: 12)
  end

  def down do
    Oban.Migration.down(version: 1)
  end
end
```

`mix ecto.migrate`

# 3. Ajouter la configuration Oban

Dans `config/config.exs`

```elixir
config :my_app, Oban,
  engine: Oban.Engines.Basic,
  repo: MyApp.Repo,
  queues: [default: 10]
```

| Option   | Rôle                                 |
| -------- | ------------------------------------ |
| `engine` | moteur d’exécution des jobs          |
| `repo`   | repo Ecto utilisé                    |
| `queues` | nombre de jobs exécutés en parallèle |

> [!WARNING]
> `default` est utilisé ici en guise d'exemple, mais pour que les jobs s'exécutent il faut préciser le nom exact des queues définies dans les workers !

# 4. Ajouter Oban dans le superviseur

Dans `lib/my_app/application.ex`

```elixir
def start(_type, _args) do
  children = [
    MyApp.Repo,
    {Oban, Application.fetch_env!(:my_app, Oban)}
  ]

  Supervisor.start_link(children, strategy: :one_for_one, name: MyApp.Supervisor)
end
```

# 5. Désactiver Oban dans les tests

Dans `config/test.exs`

```elixir
config :my_app, Oban,
  testing: :manual
```

Cela permet de faire en sorte que les jobs ne soient pas exécutés pendant les tests.
