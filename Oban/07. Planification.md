
# Jobs planifiés et automatisation avec Oban

Dans ce cours, nous allons apprendre à :

- créer un worker exécuté **périodiquement**
- tester un worker avec `perform_job/2`
- utiliser le **plugin Cron d’Oban**
- démarrer une instance Oban avec des plugins
- inspecter les jobs dans la base
- manipuler les queues à l’exécution


# 1. Création du worker DailyDigest

Les restaurateurs veulent recevoir un **email quotidien** indiquant :

- le nombre de commandes
- les revenus de la journée

Nous allons créer un worker `DailyDigest` qui récupère tous les restaurants actifs et leur envoie un digest à chacun

---

## Worker

```elixir
defmodule MyApp.DailyDigest do
  use Oban.Worker, queue: :email

  @impl Worker
  def perform(_job) do
    Enum.each(
      MyApp.all_active_restaurants(),
      &MyApp.deliver_daily_digest/1
    )
  end
end
```
# 2. Test du worker

Avant d’automatiser les jobs, il faut vérifier que le worker fonctionne.

```elixir
defmodule MyApp.DailyDigestTest do
  use MyApp.ObanCase

  test "delivering digest emails to all active restaurants" do
    %{id: id_1, name: name_1} = insert(:restaurant, :active)
    %{id: id_2, name: name_2} = insert(:restaurant, :inactive)
    %{id: id_3, name: name_3} = insert(:restaurant, :active)

    assert :ok = perform_job(MyApp.DailyDigest, %{})

    assert_received {:delivered, ^id_1}
    refute_received {:delivered, ^id_2}
    assert_received {:delivered, ^id_3}

    IO.puts("Digest delivered to:\n\n* #{name_1}\n* #{name_2}\n* #{name_3}")
  end
end
```

# 3. Automatiser les jobs avec Cron

Maintenant que le worker fonctionne, nous allons planifier son exécution.

Oban utilise des **plugins** pour automatiser certaines tâches.

Le plugin **Cron** permet de créer des jobs **à intervalle régulier**.

Nous allons créer une configuration pour lancer le worker **toutes les minutes** et démarrer la queue email **en pause**


## Configuration

```elixir
conf_opts = [
  repo: MyApp.Repo,
  queues: [email: [limit: 1, paused: true]],
  plugins: [
    {Oban.Plugins.Cron,
     crontab: [
       {"* * * * *", MyApp.DailyDigest}
     ]}
  ]
]

Oban.Config.validate(conf_opts)

Oban.start_link(conf_opts)
```

Si la configuration est invalide :

* Oban renvoie une erreur
* l’instance ne démarre pas


Une fois la configuration validée :


Le plugin Cron va maintenant créer un job `DailyDigest` **toutes les minutes**

Cependant la queue est **en pause**, donc les jobs vont s’accumuler.

## Expression CRON de periodicité

Dans cet exemple, **la minute d’attente est définie dans l’expression Cron** utilisée par le plugin **Oban.Plugins.Cron**.

Elle est ici :

```elixir
crontab: [
  {"* * * * *", ChowMojo.DailyDigest}
]
```

L’expression :

```
* * * * *
```

est une **expression cron standard** composée de 5 champs :

```
minute hour day_of_month month day_of_week
```

Dans ce cas :

```
* * * * *
```

signifie :

| champ        | valeur | signification             |
| ------------ | ------ | ------------------------- |
| minute       | `*`    | chaque minute             |
| hour         | `*`    | chaque heure              |
| day_of_month | `*`    | chaque jour               |
| month        | `*`    | chaque mois               |
| day_of_week  | `*`    | chaque jour de la semaine |

### Exemples d’expressions Cron utiles

#### Tous les jours à minuit

```
0 0 * * *
```

#### Toutes les 10 minutes

```
*/10 * * * *
```

#### Tous les jours à 8h

```
0 8 * * *
```

#### Tous les lundis à 9h

```
0 9 * * 1
```

# 4. Reprendre la queue

Nous pouvons compter les jobs avec une requête Ecto.


## Requête

```elixir
import Ecto.Query

Oban.Job
|> where([j], j.queue == "email")
|> group_by(:state)
|> select([j], {j.state, count()})
|> MyApp.Repo.all()
```

### Résultat possible

```
[
  {"available", 5}
]
```

Cela signifie que 5 jobs en sont en attente.

Pour permettre aux jobs de s’exécuter :

```elixir
Oban.resume_queue(queue: :email)
```

La queue redémarre et les jobs commencent à être traités.

# À retenir

Les plugins Oban permettent d’automatiser beaucoup de choses :

* **Cron** → jobs planifiés
* **Pruner** → nettoyage des anciens jobs
* **Lifeline** → récupération des jobs bloqués
* **Stager** → promotion des jobs planifiés

Ils sont essentiels pour faire tourner Oban **en production**.
